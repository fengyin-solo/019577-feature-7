## 题目内容

制作一个面向中学生的交互式光学设计编程项目，要求以html格式开发 确保简洁易用 包含各种形状和材料的透镜 例如非球面透镜 低色散镜片 高折射率镜片等 具有可视化操控界面和2D光路实时渲染 系统应有第一次打开的引导界面和跨设备兼容性

## 项目介绍

面向中学生的交互式光学设计学习工具，通过可视化方式帮助学生理解透镜成像规律。

### 核心特性

- 透镜类型：凸透镜、凹透镜、平面透镜、非球面透镜
- 特殊材料：低色散镜片、高折射率镜片、普通玻璃（以阿贝数 Vd 区分色散强弱）
- 入射倾角调节：平行光可斜入射，超出有效范围时提示并保留原值
- 三色光路（红/绿/蓝）实时色散渲染，斜入射时色散最直观
- 2D光路实时渲染（Canvas 2D API）
- 首次使用引导界面
- 跨设备响应式布局（手机、平板、电脑）

### 光路规律

- 凸透镜：光线向光轴会聚；凹透镜：光线向外发散；平面透镜：方向不变只侧移
- 斜入射时平行光会聚到后焦面的轴外点 (f, f·tanθ)，焦点随倾角移动
- 色散：蓝光折射率最大、偏折最多，红光最少；阿贝数越小（高折射率片≈25 < 普通玻璃≈45 < ED片≈90）色散越明显
- 球面透镜：边缘光线偏折过度产生球差，曲率越大球差越大
- 非球面透镜：同一套偏折规律下去掉边缘过偏折项，任意倾角下各光线都精确会聚到同一焦点
- 画布渲染与测验判定共用同一个光线追迹分析器（Physics.analyzeLens）
