# 中学生交互式光学设计编程项目

## How to Run

```bash
# Docker 运行（推荐）
docker-compose up --build -d

# 访问应用
# 用户端: http://localhost:8081

# 或直接用浏览器打开 frontend-user/index.html
```

| frontend-user | 8081 | 光学设计交互应用 |

## 题目内容

制作一个面向中学生的交互式光学设计编程项目，要求以html格式开发 确保简洁易用 包含各种形状和材料的透镜 例如非球面透镜 低色散镜片 高折射率镜片等 具有可视化操控界面和2D光路实时渲染 系统应有第一次打开的引导界面和跨设备兼容性

## 项目介绍

面向中学生的交互式光学设计学习工具，通过可视化方式帮助学生理解透镜成像规律。

### 核心特性

- 透镜类型：凸透镜、凹透镜、平面透镜、非球面透镜
- 特殊材料：低色散镜片、高折射率镜片、普通玻璃
- 2D光路实时渲染（Canvas 2D API）
- 首次使用引导界面
- 跨设备响应式布局（手机、平板、电脑）

### 光路规律

- 凸透镜：光线向光轴会聚（球面透镜有球差，斜入射还有彗差样轴外像差）
- 凹透镜：光线向外发散，反向延长线交于虚焦点
- 平面透镜：垂直入射不偏折，斜入射只侧移
- 非球面透镜：更精准会聚，消除球差与轴外像差
- 斜入射：工具栏可调入射倾角（-30°~30°，有效范围依画布与透镜位置自动收窄，越界提示并保留原值），焦点移到焦平面上
- 色散：蓝光（F线）偏折最多、红光（C线）最少；阿贝数越小的材料（普通玻璃40、高折30）色散越明显，ED玻璃（80）几乎无色散

### 技术栈

HTML5 + CSS3 + JavaScript（原生无依赖）
